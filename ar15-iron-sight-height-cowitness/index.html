AR-15 iron sight height and co-witness (flip-up BUIS)

Sight height is mostly about how the front post and rear aperture sit in your optic window—absolute co-witness centers them; lower-1/3 parks them in the bottom third. Flip-up sets like Ozark Armament FBUIS-B only enter that picture when raised.

Height is an optic-mount problem first

  1. Pick absolute vs lower-1/3 based on how you want the window to look with irons up.
  2. Choose an optic mount height that matches that plan.
  3. Mount FBUIS-B front and rear on Picatinny so both posts share one height when flipped up.
  4. Use elevation dials for zero—not to invent a co-witness the mounts cannot deliver.
